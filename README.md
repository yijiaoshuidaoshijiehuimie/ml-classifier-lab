# 机器学习智能分类系统

## 项目介绍
基于scikit-learn的葡萄酒品种分类系统，使用Pipeline统一预处理和模型，Streamlit做交互推理界面。

## 技术栈
- scikit-learn 1.7.2
- Streamlit 1.50.0
- Python 3.11/3.12

## 启动方法
1. 安装依赖：pip install -r requirements.txt
2. 训练模型：python src/train.py
3. 启动界面：streamlit run app.py

## 个人实现范围
- 数据加载与训练测试划分
- Logistic Regression和Random Forest两种模型比较
- Pipeline统一预处理流程
- Streamlit交互预测界面
